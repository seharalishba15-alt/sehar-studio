# SEHAR Studio

A modern fashion store concept featuring unstitched lawn, ready-to-wear, and accessories, with a fully functional shopping cart and WhatsApp-based checkout.

## Features
- Product catalog with category filters (Unstitched, Ready to Wear, Accessories)
- Live product search
- Shopping cart with quantity controls
- Checkout sends order details directly to WhatsApp
- Dark mode toggle
- Fully responsive design

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
